# 미션 - 점심 메뉴 추천

# 구현 기능 목록
1. [출력] 서비스 시작 문구를 출력한다.

2. [입력] 코치의 이름을 입력받는다.
   - [예외 처리] 코치 이름이 2 ~ 4글자가 아니면 예외를 발생시킨다.
   - [예외 처리] 코치 인원 수가 2 ~ 5명이 아니면 예외를 발생시킨다.

3. [입력] 코치별 못 먹는 메뉴를 입력받는다.
   - [예외 처리] 코치별 못 먹는 메뉴가 2개 이상이면 예외를 발생시킨다.

5. [중간 과정] 코치들의 요일별 추천 메뉴를 선정한다.

6. [출력] 메뉴 추천 결과 및 서비스 종료 문구를 출력한다.


---
매일 추천 카테고리 무작위 지정 -> 각 코치들이 먹을 메뉴 추천

코치 이름 2 ~ 4글자

코치 인원 수 2 ~ 5명

각 코치 0~2개의 못 먹는 메뉴 존재

추천 못 하는 경우는 없다

한 주에 같은 카테고리는 최대 2회

각 코치에게 한 주에 중복되지 않는 메뉴 추천해야 함(같은 카테고리도 안 되고, 같은 메누도 안됨)


메뉴 추천 완료 후 프로그램 종료

카테고리 추천 -> Randoms 라이브러리 사용 -> 카테고리별 숫자가 정해져있음

메뉴 추천 -> 카테고리에 존재하는 메뉴를 shuffle해서 제일 첫 번째 값 사용(메뉴 목록은 List<String>으로 준비)

임의로 메뉴의 순서 또는 데이터를 변경하면 안 된다.

Randoms.shuffle() 메서드의 인자로 전달되는 메뉴 데이터는, 최초에 제공한 목록을 그대로 전달해야 한다.

코치에게 추천할 메뉴를 정할 때 이미 추천한 메뉴, 먹지 못하는 메뉴도 포함된 리스트를 전달해야 한다.

추천할 수 없는 메뉴인 경우 다시 섞은 후 첫 번째 값을 사용해야 한다.
